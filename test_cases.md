# Описание веб-страниц

**Главная страница:** На странице представлено название сервиса, телефоны доверия и экстренной психологической помощи, а также верхний и нижний колонтитулы (будут присутствовать на всех страницах сервиса).

---

## Блок «Авторизация и личный кабинет»

*   **Страница входа:** Открывается при нажатии иконки в правом верхнем углу страницы, пользователю предлагается ввести почту и пароль. Если аккаунта у пользователя пока нет, можно перейти на страницу регистрации.
*   **Страница регистрации:** Страница с анкетой для первичного сбора данных о пользователе. Также собирается согласие на обработку персональных данных (без него регистрация не будет завершена).
*   **Страница подтверждения почты:** Появляется после регистрации и призывает пользователя активировать аккаунт через подтверждение почты.
*   **Страница личного кабинета:** Показывает ник, привязанную почту, а также выбранную аватарку.
*   **Страница изменения данных в ЛК:** Дает возможность редактировать данные и изменить аватар.

---

## Блок «Дневник»

*   **Страница календаря:** Отображает календарь, через который можно перейти к заметке каждого дня.
*   **Страница заметок:** Включает в себя поле для ввода текста заметки, а также выбор эмоции дня и оценку ее интенсивности.

---

## Блок «Активности»

*   **Страница с выбором мини-игр:** Отображает доступные мини-игры, а также их краткое описание для удобства выбора.
*   **Страницы с мини-играми:** Показывают конкретную мини-игру, ее правила. Чтобы начать игру, пользователь должен нажать «играть».
*   **Страница с выбором тестов:** Отображает доступные тесты, а также их краткое описание для удобства выбора.
*   **Страницы тестов:** Показывают тесты и могут включать в себя разные форматы ответов: оценка по шкале, одиночный/множественный выбор ответов.
*   **Страница с выбором медитаций:** Отображает доступные медитации, а также их краткое описание для удобства выбора.
*   **Страницы медитаций:** Отображают более подробное описание медитации, а также плеер для прослушивания с возможностью паузы, перемотки вперед/назад.
*   **Страница статистики:** Показывает статистику по итогам заполнения дневника эмоций, результаты прохождения тестов и заполнения уровня стресса. Можно выбрать период отображения статистики.
*   **Оверлей с уровнем стресса:** Измеряет уровень стресса до/после активности.

---

## Другие страницы

*   **О нас:** Страница с указанием информации о разработчиках и контактами для связи.
*   **Пользовательское соглашение:** Страница с текстом пользовательского соглашения.
*   **Страница 404:** Показывается при ошибке при работе с сайтом.

# Тест-кейсы для веб-сервиса «ЭМО»

## Тест-кейс 1: Успешная авторизация пользователя

*   **ID:** TC-001
*   **Связанные требования:** [FR-001], [FR-002], [NFR-006], [NFR-009], [NFR-010]
*   **Приоритет:** Высокий (Must have)

| Поле | Описание |
| :--- | :--- |
| **Название** | Проверка успешного входа в систему с корректными учетными данными |
| **Предусловие** | 1. Пользователь зарегистрирован в системе и почта подтверждена<br>2. Пользователь не авторизован (сессия завершена)<br>3. Браузер соответствует требованиям (актуальная версия) |
| **Шаги** | 1. Открыть главную страницу веб-сервиса<br>2. Нажать на иконку в правом верхнем углу (переход на страницу входа)<br>3. Ввести корректный адрес электронной почты в поле «Почта».<br>4. Ввести корректный пароль в поле «Пароль»<br>5. Нажать кнопку «Войти» |
| **Ожидаемый результат** | 1. Система успешно проверяет данные и перенаправляет пользователя на главную страницу<br>2. В правом верхнем углу иконка гостя меняется на аватар пользователя<br>3. Пользователю становится доступен функционал (Дневник, Активности, Личный кабинет)<br>4. Система не выдает сообщений об ошибках |

**Альтернативные варианты (Негативные сценарии):**

*   **1а. Ошибка сети / Проблемы с интернет-соединением:**<br>→ Система не может отправить запрос на сервер<br>→ Пользователю отображается всплывающее уведомление: «Нет соединения с интернетом. Проверьте настройки сети и попробуйте снова»
*   **1б. Неверный логин или пароль:**<br>→ Система проверяет данные и выдает ошибку валидации<br>→ Отображается сообщение «Неверный логин или пароль»<br>→ Поле с паролем очищается, фокус возвращается на поле ввода почты (возврат к шагу 3)
*   **1в. Пустые обязательные поля:**<br>→ Пользователь пытается нажать «Войти», не заполнив почту или пароль<br>→ Кнопка не срабатывает, поля подсвечиваются красным, появляется подсказка «Заполните это поле»

## Тест-кейс 2: Регистрация пользователя и обязательное согласие на обработку ПД

*   **ID:** TC-002
*   **Связанные требования:** [NFR-012], [NFR-013]
*   **Приоритет:** Высокий (Must have)

| Поле | Описание |
| :--- | :--- |
| **Название** | Проверка блокировки регистрации без согласия на обработку персональных данных |
| **Предусловие** | Пользователь не авторизован и находится на странице регистрации |
| **Шаги** | 1. Заполнить все обязательные поля анкеты (Имя, Почта, Пароль)<br>2. Выбрать аватар из предложенных<br>3. **Не** ставить галочку в чекбоксе «Согласен на обработку персональных данных»<br>4. Нажать кнопку «Зарегистрироваться» |
| **Ожидаемый результат** | 1. Кнопка «Зарегистрироваться» неактивна<br>2. Появляется сообщение: «Для завершения регистрации необходимо согласие на обработку персональных данных»<br>3. Аккаунт не создается |

**Альтернативные варианты (Негативные сценарии):**

*   **2а. Ошибка сети при отправке данных:**<br>→ Данные формы не отправляются<br>→ Появляется уведомление «Ошибка соединения. Проверьте интернет и попробуйте снова»<br>
